## 1. Mengenal Website

Website CEMETI memiliki dua bahasa dengan tampilan yang sama: **Inggris (EN)** sebagai bahasa utama dan **Indonesia (ID)**.

Bagian-bagian website:

| Bagian | Isinya |
|---|---|
| **Beranda** | Satu konten unggulan dari Exhibition, Residency, Public Program, Open Studio, dan tiga tulisan Journal terbaru. |
| **Exhibition** | Daftar pameran (Solo atau Group). |
| **Residency** | Daftar residensi (Regular atau Research). |
| **Public Program** | Daftar program publik. |
| **Open Studio** | Daftar open studio. |
| **Open Call** | Pendaftaran terbuka, lengkap dengan formulir untuk pelamar. |
| **Journal** | Kumpulan tulisan dan esai. |
| **Open Archive** | Daftar tulisan, buklet, dan katalog yang bebas diunduh. |
| **About** | Tentang Cemeti, Advisory Board, dan Tim. |
| **History** | Kronologi kegiatan per tahun (dropdown). |
| **Support Us** | Cara mendukung Cemeti (dropdown). |
| **Contact Us** | Alamat, jam buka, dan tombol rute. |

Tampilan website sudah diatur oleh tema. Anda tidak perlu mengatur warna atau huruf. **Pekerjaan Anda hanya mengisi konten.**

## 2. Masuk dan Mengenal Menu Admin

### Cara masuk

1. Buka `https://cemeti.art/wp-admin` di browser.
2. Isi nama pengguna dan kata sandi.
3. Klik **Log In**.

> **Penting:** Jangan membagikan kata sandi lewat chat atau email. Pakai kata sandi yang panjang dan unik.

### Menu di sisi kiri

| Menu | Untuk apa |
|---|---|
| **Exhibitions** | Pameran |
| **Residencies** | Residensi |
| **Public Programs** | Program publik |
| **Open Studios** | Open studio |
| **Open Calls** | Pendaftaran terbuka |
| **Journal** | Tulisan dan esai |
| **Open Archive** | Item yang bisa diunduh (buklet, katalog, tulisan) |
| **People** | Orang di halaman About (Advisory Board dan Tim) |
| **Applications** | Lamaran yang masuk lewat Open Call (hanya bisa dilihat) |
| **Pages** | Halaman tetap (About, History, Support Us, Contact Us, dan lainnya) |

## 3. Dua Bahasa: Inggris (EN) dan Indonesia (ID)

Setiap konten bisa punya dua versi: versi EN dan versi ID. Keduanya saling terhubung. Pengunjung berpindah bahasa dengan tombol **EN/ID** di kanan atas website.

### Membuat versi bahasa lain (cara termudah)

1. Buat dan simpan konten dalam satu bahasa dulu.
2. Di layar edit, lihat kotak di sisi kanan bernama **"Cemeti: translation"**.
3. Klik tombol **"Create ID version (copy)"** (atau EN).
4. WordPress membuat salinan sebagai **draft**, lalu membukanya.
5. Terjemahkan teksnya, lalu klik **Publish**.

> Setelah itu, di kotak yang sama Anda akan melihat tautan **"edit translation"** untuk berpindah ke versi bahasa lainnya.

### Apa yang dibagi dan apa yang terpisah

| Dibagi (diubah di satu sisi, ikut di sisi lain) | Terpisah (diisi sendiri per bahasa) |
|---|---|
| Featured image (foto utama) | Judul dan isi teks |
| Tanggal mulai dan selesai | File PDF (booklet atau file unduhan) |
| Galeri foto | Biografi dan nama pemeran dalam teks |
| Foto dokumentasi | Caption (keterangan) galeri dan dokumentasi |
| | Jam, lokasi, info opening, speakers |

**Artinya:** untuk file PDF, unggah **PDF bahasa Inggris di versi EN** dan **PDF bahasa Indonesia di versi ID**. Keduanya tidak saling menimpa.

> Kalau versi ID belum dibuat, daftar di versi ID menampilkan versi EN sebagai pengganti sementara. Setelah versi ID dibuat dan dipublikasikan, yang tampil adalah versi ID.

### Menu, nama halaman, dan teks tombol

- Nama menu seperti Exhibition atau Residency memang tetap dalam bahasa Inggris di dua bahasa. Itu sesuai desain.
- Kata-kata tombol dan label (misalnya "Download Booklet" dan "Unduh Booklet") berganti sendiri sesuai bahasa.

## 4. Menulis Satu Konten, Langkah demi Langkah

Contoh: membuat **Exhibition** baru. Langkah untuk jenis konten lain hampir sama.

1. Klik **Exhibitions → Add New**.
2. **Title**: ketik judul di bagian atas.
3. **Isi teks** (kata pengantar, deskripsi): ketik di kotak besar di bawah judul.
4. **Featured image**: di sisi kanan, klik **Set featured image**, pilih atau unggah foto poster.
5. **Tipe pameran**: di sisi kanan, pilih **Solo** atau **Group**.
6. Isi kotak **Details** di bawah teks (lihat bagian 5).
7. Klik **Preview** untuk melihat hasilnya.
8. Klik **Publish**.
9. Buat versi bahasa lain lewat kotak **Cemeti: translation** (bagian 3).

> **Draft** artinya tersimpan tetapi belum tampil di website. **Publish** artinya tampil untuk semua pengunjung. **Update** muncul setelah konten dipublikasikan, dan dipakai untuk menyimpan perubahan.

## 5. Jenis-Jenis Konten

### 5.1 Exhibition (Pameran)

Kotak **Details** berisi:

| Bagian | Isi |
|---|---|
| **Dates** | Start date dan End date. Kosongkan End date kalau hanya satu hari. |
| **Artists and information** | Artists (satu nama per baris), Opening, Public program info, Venue and hours. |
| **Gallery** | Foto karya. Muncul sebagai bagian "Galeri", dua foto per baris. |
| **Documentation** | Foto dokumentasi pembukaan atau acara. |
| **Biographies** | Satu blok per seniman: foto, nama, biografi. |
| **Booklet** | File PDF buklet, atau tautan buklet di situs lain. |
| **Related publications** | Maksimal 4 konten terkait (tautannya dua arah). |
| **Search and sharing** | Deskripsi singkat untuk Google dan media sosial (sekitar 150 karakter). |

**Tips Biographies:** isi **Artists** dulu, lalu klik **"Add from Artists"** di bagian Biographies. Blok biografi otomatis dibuat sesuai nama seniman.

Di website, setiap bagian muncul **hanya kalau terisi**. Daftar isi di atas halaman (Foreword, Gallery, Documentation, dan seterusnya) juga menyesuaikan sendiri.

### 5.2 Residency (Residensi)

Mirip Exhibition. Perbedaannya:

- Tipe yang dipilih adalah **Regular** atau **Research**.
- Bagian nama diberi label **Residents** (bukan Artists).

### 5.3 Public Program

- Isi **Time** (misalnya "15.00 – 17.00 WIB") dan **Speakers**.
- Tersedia **Documentation** dan **Biographies**.

### 5.4 Open Studio

- Isi **Artists**, tanggal, dan **Documentation**.
- Tersedia **Biographies**.

### 5.5 Journal (Tulisan dan Esai)

- Isi **Author** (penulis).
- Pilih kategori: **Essay** atau **Curatorial Essay**.
- Bagian **Documentation** menampilkan foto setelah tulisan.

> Kategori **News** tidak tampil di daftar Journal. Daftar Journal hanya untuk tulisan dan esai. Konten berkategori News tidak masuk Journal.

### 5.6 Open Archive (Database Unduhan)

Open Archive adalah **daftar tulisan, buklet, dan katalog yang bebas diunduh**. Tampil dalam urutan huruf A sampai Z. Ada dua cara mengisinya:

**Cara A: membuat item baru**

1. Klik **Open Archive → Add New**.
2. Isi judul dan teks.
3. Di kotak **Details**, bagian **Download**, pilih **File to download (PDF)**, atau isi tautan file di situs lain.
4. Isi **Authors / editors** dan **Year**.
5. Di sisi kanan, pilih jenisnya: **Writing**, **Booklet**, atau **Catalog**.
6. Kalau perlu, isi **Gallery**, **Documentation**, dan **Profile** (foto, nama, teks seseorang).
7. **Publish**. Halamannya otomatis memiliki tombol **Download Booklet** (versi ID: **Unduh Booklet**).

**Cara B: menandai konten yang sudah ada**

1. Buka konten (Exhibition, Residency, Public Program, Open Studio, Open Call, atau Journal).
2. Di kotak sisi kanan **"Open Archive"**, centang **"Show in the Open Archive"**.
3. Klik **Update**. Konten itu ikut terdaftar di halaman Open Archive.

> Lakukan hal yang sama di versi bahasa lainnya (EN dan ID).

> Daftar Open Archive hanya berisi item yang Anda buat atau centang. Tidak ada yang masuk otomatis.

### 5.7 Open Call (Pendaftaran Terbuka)

Isi di kotak **Details**:

| Kolom | Artinya |
|---|---|
| **Active** | Centang = pendaftaran ini yang tampil di halaman Open Call dan menerima lamaran. Hilangkan centang untuk menutupnya seketika. |
| **Deadline** | Batas waktu. Setelah lewat, pendaftaran menutup sendiri. |
| **External application URL** | Isi hanya kalau pendaftaran dilakukan di situs lain. Kosongkan untuk memakai formulir bawaan. |
| **Required documents** | Dokumen yang diminta, dipisah koma: `cv, portfolio, proposal, motivation`. Kosong = keempatnya. Tulis `none` kalau tanpa unggahan. |

Halaman Open Call hanya menampilkan **satu** pendaftaran: yang aktif dan terbaru.

**Melihat lamaran yang masuk:** buka menu **Applications**. Klik nama pelamar untuk melihat data dan mengunduh dokumennya. Hanya administrator yang bisa mengunduh. Surel pemberitahuan dikirim ke alamat yang diatur di **Settings → Cemeti** (kolom "Application notifications go to").

### 5.8 People (halaman About)

Menu **People** mengisi bagian **Advisory Board** dan **Team** di halaman About.

1. Klik **People → Add New**.
2. **Title**: nama.
3. **Title / role**: jabatan atau peran.
4. Untuk Advisory Board, isi **Short quote** (kutipan singkat). **Featured image** = foto persegi.
5. Di sisi kanan, pilih grup: **Advisory Board** atau **Team**.
6. Urutan tampil diatur lewat **Order** (Page attributes).

## 6. Halaman Tetap

Halaman-halaman ini ada di menu **Pages**. Setiap halaman punya versi EN dan ID.

### 6.1 About

- Foto utama = **Featured image**.
- Teks tentang Cemeti diisi di editor.
- Advisory Board dan Team muncul otomatis dari menu **People**.

### 6.2 History (Kronologi)
Tampil sebagai baris dropdown per tahun.

1. Buka **Pages → History**.
2. Cari kotak **"History (chronology)"**.
3. Klik **Add Year**, tulis tahunnya (misalnya 2026).
4. Di kotak **"Exhibitions and events"**, tulis satu kegiatan per blok. **Pisahkan antar kegiatan dengan satu baris kosong.**
5. Baris pertama setiap blok = nomor dan tanggal, misalnya `375. 12 – 30 Oktober 2026`. Baris di bawahnya = judul, seniman, program, dan seterusnya.
6. Klik **Update**. Lakukan juga di halaman History versi bahasa lainnya.

> Setiap tahun tinggal klik **Add Year** untuk tahun baru. Urutan tampil: tahun terlama di atas.

### 6.3 Open Archive (halaman)
Isi teks pembuka diatur di **Pages → Open Archive**. Daftarnya diatur seperti pada bagian 5.6.

### 6.4 Support Us

- Teks pembuka di **Pages → Support Us**.
- Setiap **baris dropdown** adalah **halaman anak** (sub-halaman) dari Support Us: Patron of Cemeti, Friends of Cemeti, Annual Benefit, Collaboration.
- Untuk mengubah isi sebuah baris, buka sub-halaman itu di **Pages** dan ubah teksnya.
- Untuk menambah baris, buat halaman baru dengan **Parent = Support Us**.

### 6.5 Contact Us

1. Buka **Pages → Contact Us**.
2. Isi kotak **"Contact details"**: Address, Opening hours, Email, Phone / WhatsApp, Google Maps link.
3. Kolom yang kosong akan memakai data dari **Settings → Cemeti**.
4. Tombol **"Plan your Route"** hanya menerima alamat Google Maps.

### 6.6 Kalau halaman tampil dengan desain yang salah
Di sisi kanan halaman ada kotak **"Cemeti page design"**. Pilih desain yang sesuai (misalnya About atau Support Us). Atur juga di versi bahasa lainnya.

## 7. Pengaturan Umum (Settings → Cemeti)

Buka **Settings → Cemeti**. Halaman ini punya dua bagian: **English** dan **Bahasa Indonesia**. **Isi keduanya.**

| Kolom | Dipakai untuk |
|---|---|
| **Institution name** | Nama di footer, judul tab browser, dan Google |
| **Site description** | Deskripsi singkat untuk Google dan media sosial |
| **Address** | Alamat di footer dan menu |
| **Opening hours** | Hari dan jam buka di footer |
| **Email** | Email di footer |
| **Application notifications go to** | Alamat penerima surel lamaran Open Call |
| **Instagram / Youtube / Facebook URL** | Tautan media sosial di footer |
| **Google Maps route URL** | Tombol rute |
| **Opening splash (What's on)** | Centang untuk **mematikan** splash di beranda |

> Kalau kolom Institution name, Address, atau Opening hours dibiarkan kosong, website memakai teks bawaan bahasa itu. Teks bawaan terlihat sebagai tulisan abu-abu di kolomnya.

### Tombol pemeliharaan (di bagian atas Settings → Cemeti)

| Tombol | Kapan dipakai |
|---|---|
| **Create missing pages** | Membuat halaman tetap yang belum ada |
| **Set Solo/Group on exhibitions without a type** | Mengisi tipe pameran yang kosong |
| **Set missing featured images** | Mengisi foto utama yang kosong dari gambar lain di konten |
| **Make missing picture sizes** | Setelah import atau migrasi: membuat ukuran gambar yang kurang, supaya halaman cepat |
| **Clear cached pages** | Kalau perubahan belum terlihat di website |

> Tombol yang berjalan bertahap menampilkan kemajuan di layar. **Jangan menutup halaman** sampai selesai.

## 8. Gambar dan File PDF

### Foto yang baik

- Format **JPG** (atau PNG untuk gambar bergrafis).
- Sisi terpanjang sekitar **1600 sampai 2000 piksel**.
- Ukuran file idealnya **di bawah 1 MB**. File besar membuat halaman lambat.
- Beri nama file yang jelas, misalnya `kerja-bakti-monumen-2025.jpg`.

### Menambahkan foto ke Gallery atau Documentation

1. Di kotak **Details**, klik tombol untuk menambah foto.
2. Pilih atau unggah beberapa foto sekaligus.
3. Atur urutan sesuai yang Anda inginkan.
4. Isi **Gallery caption** atau **Documentation caption** kalau perlu.

### File PDF (buklet atau file unduhan)

1. Di field PDF, klik tombol untuk memilih file.
2. Unggah PDF atau pilih dari **Media Library**.
3. **Versi EN dan ID punya field PDF sendiri-sendiri.** Isi masing-masing dengan PDF bahasanya.
4. Alternatif: isi **"or link to a booklet elsewhere"** kalau file ada di situs lain. Ini hanya dipakai kalau tidak ada PDF di atasnya.

### Menghapus atau mengganti

- Menghapus foto dari konten **tidak menghapusnya dari Media Library**.
- Untuk membersihkan, buka **Media**, pilih file, lalu **Delete Permanently**. Pastikan file itu tidak dipakai di tempat lain.

| **Pencarian** | Mencari di judul dan teks semua konten. |

## 10. Masalah yang Sering Terjadi

| Gejala | Kemungkinan penyebab dan cara mengatasi |
|---|---|
| **Perubahan tidak terlihat di website** | Buka **Settings → Cemeti → Clear cached pages**. Lalu muat ulang browser dengan **Ctrl+Shift+R** (Windows) atau **Cmd+Shift+R** (Mac). |
| **Konten tidak muncul di versi ID (atau EN)** | Versi bahasa itu belum dibuat atau masih **Draft**. Buat lewat kotak **Cemeti: translation**, lalu **Publish**. |
| **Gambar tidak muncul (ikon gambar rusak)** | File gambar hilang atau belum lengkap di server. Buka alamat gambarnya di tab baru. Kalau hasilnya "Page not found", unggah ulang gambar itu, atau hubungi pengembang. |
| **Halaman terasa berat** | Gambar terlalu besar. Kecilkan gambar sebelum diunggah. Setelah import, jalankan **Make missing picture sizes**. |
| **File PDF di EN dan ID tertukar** | Isi field PDF di masing-masing versi bahasa (bagian 3). |
| **Journal kosong** | Tulisan masih berkategori **News** (disembunyikan di Journal), atau belum diberi bahasa. Cek kategori dan bahasanya. |
| **Splash tidak muncul** | Splash hanya tampil sekali per kunjungan, dan hanya kalau ada konten Exhibition, Open Studio, atau Residency. Cek juga apakah **Opening splash** dimatikan di **Settings → Cemeti**. Coba jendela Incognito. |
| **Halaman tidak ditemukan (404) setelah ada perubahan** | Buka **Settings → Permalinks** lalu klik **Save Changes** (tanpa mengubah apa pun). |
| **Biografi, galeri, atau dokumentasi kosong di konten lama** | Buka konten, cari kotak **"Cemeti: split the old text"** di sisi kanan, klik **Split the text into the fields**. Foto dan biografi dari teks lama dipindahkan ke field-nya. Ada tombol **Undo**. |
| **Lupa kata sandi** | Di halaman login, klik **Lost your password?**. |

> Kalau masalah tidak teratasi, catat: halaman mana, apa yang Anda klik, dan apa yang terlihat. Kirim **screenshot** ke pengembang. Itu paling membantu.

## 11. Perawatan Rutin

### Setiap kali menambah konten

- Isi kedua bahasa.
- Cek tampilan di ponsel (buka dari ponsel atau perkecil jendela browser).
- Cek tautan dan tanggal.

### Setiap bulan

- Cek **Dashboard → Updates**. Perbarui plugin satu per satu, dan cek website setelahnya.
- Jangan memperbarui tema tanpa konfirmasi pengembang. Tema Cemeti dibuat khusus.
- Hapus komentar spam kalau ada.

### Backup

- Backup dilakukan dengan plugin **UpdraftPlus**.
- **Simpan backup di luar server** (misalnya Google Drive atau hard disk eksternal), bukan hanya di hosting.
- Lakukan backup manual sebelum perubahan besar (pembaruan plugin, atau perubahan struktur).

### Keamanan

- Pakai kata sandi yang panjang dan unik. Aktifkan verifikasi dua langkah kalau tersedia.
- Beri akses seperlunya: **Editor** untuk yang mengurus konten, **Administrator** hanya untuk yang mengurus pengaturan.
- Jangan membagikan kata sandi lewat chat atau email.

### Jangan diubah tanpa pengembang

- Pengaturan plugin **Polylang** (bahasa dan sinkronisasi).
- Pengaturan di **Tools → Cemeti Converter** (alat migrasi dari website lama).
- File tema dan struktur database.

## 12. Daftar Periksa Sebelum Menekan Publish

- [ ] Judul benar dan tidak ada salah ketik.
- [ ] **Featured image** terpasang.
- [ ] Tanggal mulai dan selesai terisi.
- [ ] Nama seniman atau pembicara terisi.
- [ ] Galeri, dokumentasi, dan biografi sudah dicek (bagian yang kosong tidak tampil).
- [ ] File PDF terpasang di **setiap** versi bahasa.
- [ ] Tipe sudah dipilih (Solo/Group, Regular/Research, kategori Journal).
- [ ] **Preview** sudah dicek di komputer dan ponsel.
- [ ] Versi bahasa lain sudah dibuat dan diterjemahkan.
- [ ] Kalau perlu, centang **Show in the Open Archive**.

## 13. Istilah yang Sering Muncul

|---|---|

| **Open Archive** | Daftar tulisan dan buklet yang bebas diunduh. |

| **Permalinks** | Pengaturan bentuk alamat halaman. |
