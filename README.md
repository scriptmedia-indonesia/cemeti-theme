# Cemeti — website theme

Child theme `scriptmedia-cemeti` for **Cemeti – Institut untuk Seni dan Masyarakat**, built on the Scriptmedia Core plugin and `scriptmedia` parent theme.

- Install: zip `themes/scriptmedia-cemeti/` and upload; activate with the parent theme `scriptmedia` present.
- Requires: WordPress 6.6+, PHP 8.1+. Soft dependencies: Scriptmedia Core, Secure Custom Fields, Polylang, Elementor.
- Docs: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md), [`docs/DESIGN-NOTES.md`](docs/DESIGN-NOTES.md).
- Design source: `design/cemeti-design.pdf`.

Status: **M1 (foundation) complete**; M2–M5 pending. See `docs/ARCHITECTURE.md`.
