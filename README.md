# Cemeti — website theme

Standalone WordPress theme `scriptmedia-cemeti` for **Cemeti – Institut untuk Seni dan Masyarakat**. It needs no parent theme. Scriptmedia Core is an optional integration.

- Install: zip `themes/scriptmedia-cemeti/`, upload via Appearance → Themes, activate. Edit address, hours and social links under Settings → Cemeti. Content types (Exhibition, Residency, Public Program, Open Studio, Open Call, Journal) appear in the admin menu; after activating, open Settings → Permalinks and click Save once if URLs 404.
- Requires: WordPress 6.6+, PHP 8.1+. Optional: Polylang (ID/EN switcher), Secure Custom Fields, Scriptmedia Core.
- Docs: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md), [`docs/DESIGN-NOTES.md`](docs/DESIGN-NOTES.md).
- Design source: `design/cemeti-design.pdf`.

Status: **M1 (foundation) and M2 (content model) complete**; M3–M5 pending. See `docs/ARCHITECTURE.md`.
